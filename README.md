# Hêdî Hêdî – Webseite

Statische Webseite der App **Hêdî Hêdî** (Kurmanji lernen, Schritt für Schritt). Sie wird über GitHub Pages aus dem Ordner `public/` veröffentlicht.

Der Inhalt von `public/` wird aus dem (privaten) App-Repo gespiegelt und dort gepflegt. Änderungen bitte nicht hier von Hand machen, sie würden beim nächsten Veröffentlichen überschrieben.
